A persisted cross-store reference carries its owner `workspace` and `store_root`. Resolve the reference workspace against the aggregate process root: `workspace="default"` selects that root, while another workspace name resolves to its path beneath that root. Resolve a relative `store_root` beneath the resulting owner workspace, not beneath the validator's current `local_workspace`. The same reference must resolve to the same target id and classification from aggregate and nested invocation roots. Resolution is read-time only and does not rewrite the reference fields. Preserve supported absolute `store_root` overrides.
